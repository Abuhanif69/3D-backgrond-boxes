#📦 3D Boxes Background
A fun and interactive UI experiment that creates a 3D box illusion by splitting a single background image into multiple animated tiles. 
Clicking the button toggles a smooth transformation effect that brings the boxes together and apart.
--


#✨ Features
--
🎩 Interactive Magic / Reset toggle button
🧱 3D illusion built with pure CSS pseudo-elements
🖼️ Background image split dynamically using JavaScript
🎨 Smooth transitions and rotations
⚡ No libraries — Vanilla HTML, CSS & 

🛠️ Built With
HTML5 – Structure
CSS3 – Flexbox, transforms, pseudo-elements
JavaScript (ES6) – DOM manipulation & event handling
